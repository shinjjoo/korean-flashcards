# 🎒 초등학교 1학년 맞춤형 한글 단어 플래시 카드 & A4 주제별 단어장

초등학교 1학년 학생들의 초기 한글 학습과 어휘력 향상을 위해 제작된 **인터랙티브 한글 플래시 카드 및 A4 포스터 웹 프로그램**입니다.  
총 **219개의 필수 기초 어휘**가 수록되어 있으며, 화면 학습은 물론 가정이나 교실에서 즉시 오려 쓸 수 있는 **A4 종이 카드 인쇄** 및 **주제별 A4 단어장 포스터 기능**까지 모두 지원합니다.

👉 **웹사이트 바로가기**: [https://shinjjoo.github.io/korean-flashcards/](https://shinjjoo.github.io/korean-flashcards/)

---

## 📂 파일 구성 안내

- **`index.html`**: 단어 카드 웹 화면 및 낱장 인쇄 뷰어 (글씨 우선 표시 & 그림 힌트 모드)
- **`poster.html`**: A4 1장에 1개 주제의 모든 단어(25~32개)가 쏙 들어가는 주제별 단어장 뷰어
- **`words.js`**: 219개 단어 전체 데이터 (로컬 및 웹 환경에서 CORS 없이 즉시 로드)
- **`words.json`**: 다른 프로그램이나 엑셀 등으로 가공하기 편한 표준 JSON 단어 데이터
- **`README.md`**: 본 설명서

## 🌟 주요 학습 기능 및 사용법

### 1. 글씨 우선 & 그림 힌트 모드
- **글씨 먼저 보기**: 아이들이 그림에만 의존하지 않고 글자를 먼저 또박또박 읽는 연습을 유도합니다.
- **💡 그림 힌트 버튼**: 버튼을 톡 누르거나 단축키 `H`를 누르면 귀여운 그림(이모지)이 뿅 하고 나타납니다.
- **자동 리셋**: 다음 단어로 넘어가면 힌트가 자동으로 닫혀 새로운 글씨에 다시 집중할 수 있습니다.

### 2. 3D 플립 카드 (앞면 / 뒷면)
- **앞면**: 커다란 단어 글씨, 그림 힌트, 주제 및 받침 여부 안내 배지, 🔊 한국어 소리 듣기(TTS)
- **뒷면**: 1학년 눈높이의 쉬운 뜻풀이, 교과서 맞춤 예문, 자모 분해(초성+중성+종성)

### 3. 편리한 단축키
- <kbd>◀</kbd> <kbd>▶</kbd> : 이전 / 다음 단어 넘기기
- <kbd>Space</kbd> : 카드 앞뒤 뒤집기 (뒷면 설명 확인)
- <kbd>H</kbd> : 그림 힌트 열기 / 닫기
- <kbd>Enter</kbd> : 또박또박 한국어 발음 듣기

### 4. 다양한 학습 필터 및 도구
- **8대 주제별 모아보기**: 가족과 사람, 동물과 곤충, 과일과 채소, 학교와 학용품, 우리 몸과 옷, 자연과 날씨, 탈것과 동네, 음식과 생활
- **받침별 맞춤 학습**: 🟢 받침 없는 단어(71개) / 🔵 받침 있는 단어(148개)
- **⭐ 별표 단어 복습**: 헷갈리는 단어만 북마크하여 모아보기
- **🎲 순서 섞기 / ▶ 자동 넘김**: 무작위 퀴즈 및 4초 간격 자동 슬라이드쇼

### 5. 🖨️ 풍부한 인쇄 지원
- **오려 쓰는 낱장 카드**: A4 1장에 8장씩 실물 플래시 카드로 인쇄
- **주제별 포스터 단어장**: A4 1장에 한 주제의 모든 단어가 들어가는 8쪽 분량의 한눈에 쏙 단어장 (`poster.html`)
